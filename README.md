# 学术资料管理系统 · Academic Manager

一个**本地优先**的个人学术资料管理系统:管理论文 / 评论 / 草稿等**作品**、科研**项目**、**投稿轮次**、**标签**,并提供数据**看板**与**导出 / 备份恢复**。单人使用,数据全部存在本地 SQLite,可随时打包迁移到自有 VPS。

> 演示数据均为虚构占位示例(`src/db/seed.ts`),不含任何真实个人信息。

## ✨ 功能

- **作品管理**:论文 / 评论 / 草稿 / 其他成果的增删改查,按类型 / 状态 / 标签筛选 + **全文搜索(标题/摘要/作者/备注)+ 发表日期区间** + 分页;**粘贴 DOI 一键从 Crossref 导入元数据**(标题/作者/期刊/日期,离线可手填);详情页 **一键打开本机文件 / 在文件夹中定位 / 复制路径**。
- **项目管理**:科研项目 CRUD,挂接产出成果(项目 ↔ 作品多对多),**结构化经费(金额 + 币种)**。
- **投稿追踪**:每个作品的多轮投稿记录(期刊 / 轮次 / 状态 / 投稿与决定日期);全局「在投」视图,超期(>90 天在审)高亮提醒。
- **标签**:多对多打标签(作品与项目通用),按主题浏览,标签管理与重命名。
- **数据看板与科研分析**:年度发表数、主题分布、各刊平均审稿周期、当前在投、结题提醒,以及**录用率 / 投稿趋势 / 累计发表曲线 / 作者角色·类型分布 / 经费汇总**(Recharts,图表懒加载)。
- **报告与导出**:**年度报告一键生成**(`/reports`,按年份汇总发表/投稿/立项/结题,复制 Markdown 直接交述职);成果清单(按年 / 类型 × Markdown / 纯文本 / **Word `.docx`**,可复制下载)、**引用格式 APA / GB-T 7714 / BibTeX**、项目结题成果清单、**截止日历 `.ics` 导出**(投稿超期 + 项目结题,导入系统日历到点提醒)、**整库 JSON 备份导出与一键恢复**(带结构 / 引用完整性校验 + 二次确认)。
- **容灾**:启动自动滚动备份(完整性自检 + 保留最近 14 份)+ `/health` 展示最近备份与异地副本提醒;字体本地自托管,**离线也能首次构建启动**。
- **⌘K 命令面板**:全局快捷键(⌘K / Ctrl+K)跳转各区、新建作品/项目、模糊搜索作品/项目/标签。
- **数据体检(`/health`)**:集中检出口径/语义异常(已发表缺日期、投稿中无记录、孤儿标签等)并深链订正,孤儿标签一键清理;**DB 级 CHECK 约束**在写入层兜底脏数据。

## 🧱 技术栈

- **Next.js 16**(App Router)+ **React 19** + **TypeScript**(strict)
- **Tailwind CSS v4** + **shadcn/ui**(Radix)+ **lucide** 图标 + next-themes
- **Drizzle ORM** + **better-sqlite3**(同步驱动,Windows 有预编译二进制)
- **Recharts** 图表;**zod** 校验;**Vitest** 测试

## 🚀 快速开始

前置:Node.js ≥ 20。

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量(仅一个:数据目录,默认 ./data)
cp .env.example .env.local

# 3. 建库(应用迁移)
npm run db:migrate

# 4. (可选)灌入示例演示数据
npm run db:seed

# 5. 启动开发服务器
npm run dev
```

打开 http://localhost:3000 即可使用。

## 📦 数据与备份

- 数据库为单文件 SQLite,路径由 `DATA_DIR` 决定(默认 `./data/app.db`),**已在 `.gitignore` 中忽略**。
- 一级备份:直接复制 `data/` 目录。
- 二级备份:应用内「导出」页可下载整库 JSON,并支持**一键恢复回灌**(覆盖前二次确认)。

## ☁️ 运行方式

**本项目仅在本机运行(不上 VPS)。** Windows 下双击桌面「学术资料库.cmd」即可(首启自动构建,随后 `next start` 并打开浏览器)。

仓库附带的多阶段 `Dockerfile` / VPS 说明([`DEPLOY.md`](./DEPLOY.md))作为**保留的可选能力**(便于他人克隆后容器化),非本项目的目标或支持路径。设计蓝本见 [`PROJECT_SPEC.md`](./PROJECT_SPEC.md),版本路线图见 [`ROADMAP.md`](./ROADMAP.md)。
